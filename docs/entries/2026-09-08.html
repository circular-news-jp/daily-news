2026/09/08 のダイジェスト

2026/09/08

1. 政策・法規制

  • 環境省は、2026年9月3日に「脱炭素×復興まちづくりプラットフォーム総会」の開催を発表しました。
  • 環境省は、2026年9月7日付（2026年9月6日発表）で、「資源循環加速化事業」において9件の事業採択を行ったことを発表しました。
  • 経済産業省と環境省は、2026年9月7日付（2026年9月6日発表）で、プラスチック資源循環の推進に向けた「循環型設計の高度化」や「マスバランス等の価値表示のあり方」を検討するため、3つのタスクフォースを設置したことを明らかにしました。
  • 経済産業省は、2026年9月4日に「重要鉱物に係る安定供給確保を図るための取組方針の改正案」に対する意見公募（パブリックコメント）を開始しました。

2. 技術・研究動向

  • 株式会社カウネットは、2026年9月2日にオフィスから排出される複合プラスチックを回収・再生する「Office Plastic Recycling Project 2026」実証実験を実施し、再生パネルを展示会で公開すると発表しました。
  • JFEエンジニアリング株式会社は、2026年9月7日に、国連気候変動枠組条約第31回締約国会議（COP31）のジャパン・パビリオンで、廃棄物を水素・一酸化炭素へ変える独自のケミカルリサイクル技術「C-PhoeniX Process®」を紹介することを発表しました。
  • JX金属サーキュラーソリューションズ（JXCS）は、2026年9月3日、KDDIとローソンが実施するAI自動分別リサイクルボックス「Bin-e」を活用した使用済みリチウムイオン電池内蔵製品の回収実証に参画し、回収品の収集・運搬・リサイクルを担うと発表しました。
  • 日刊産業新聞は、2026年9月8日に開催された「鉄スクラップ高度循環研究会」で破砕・選別技術に関する講演が行われたと報じ、UACJはアルミのアップグレードリサイクルに向けた画像選別技術の開発に取り組んでいることを示しました。

3. 産業動向

  • 株式会社カウネットは、コクヨ、トランスコスモス、森ビルと連携し、2026年9月2日にオフィス排出複合プラスチックのリサイクル実証実験「Office Plastic Recycling Project 2026」の実施を発表しました。
  • 株式会社ロフトは、2026年9月1日より「ロフト グリーンプロジェクト リサイクルプログラム 2026」を開始し、42の化粧品ブランド・メーカーと協力して化粧品容器などの回収リサイクルを継続・拡大します。
  • 住友精化は、2026年9月7日付（2026年8月31日発表）で、使用済み紙おむつに含まれる吸水性樹脂のケミカルリサイクルに関するパイロット設備を姫路工場で稼働させ、2030年度の社会実装を目指し自治体やパートナー企業との連携を進めると報じられました。
  • 萩原工業株式会社は、2026年9月7日、株式会社日本政策投資銀行（DBJ）との資本業務提携契約を締結し、ブルーシート水平リサイクル推進を含む環境事業の拡大を加速することを発表しました。

4. 海外規制・市場

  • 欧州では、2026年に「EU循環経済法（CEA）」が採択される予定で、二次原料の単一市場確立と循環材利用率の向上を目指しています。また、「持続可能な製品のためのエコデザイン規則（ESPR）」の製品別義務は2026年から順次適用が始まり、鉄鋼・アルミが最初の対象となります。
  • 欧州バッテリー規則（EU 2023/1542）は2026年もバッテリー業界に影響を与えており、2027年からのデジタル製品パスポート義務化や再生材含有率の表示義務化に向けて、メーカーは準備を進める必要があります。
  • 中国では、2026年7月3日に発表された「循環経済発展十五五規画」で海外の良質な再生資源の輸入拡大方針が示されましたが、2026年8月15日施行の「生態環境法典」により使い捨てプラスチック製品の生産・販売・使用が厳しく制限され、違反時には罰金が科されることになっています。
  • 米国では、2026年9月1日にリサイクル定義の連邦標準化と再生材含有率に関する主要なリサイクル法案が下院小委員会で進展しました。 また、カリフォルニア州では2026年1月1日からプラスチック製レジ袋が全面禁止となり、紙袋にはリサイクル材料の最低含有率が義務付けられています。
