2026/08/03 のダイジェスト

2026/08/03

1. 政策・法規制

  • 環境省は2026年7月27日、「令和7年度補正予算 地域資源の徹底活用に向けた資源循環加速化事業（モデル事業）」の公募採択結果を公表し、建設解体現場からの廃窓リサイクル、一般廃棄物の全量資源化システム構築、海岸漂着プラスチックの島内資源循環など9件の事業を採択しました。
  • 環境省は2026年7月31日、中央環境審議会循環型社会部会の第1回食品リサイクル小委員会の開催を発表しました。
  • 2026年4月に施行された改正資源有効利用促進法は、再生プラスチックの利用義務化、環境配慮設計の認定制度新設、自主回収・再資源化の促進、およびCEコマース事業者（シェアリング等）の基準設定を柱としています。
  • 環境省は2026年7月24日、「廃棄物の処理及び清掃に関する法律施行令の一部を改正する政令案」に対する意見募集（パブリックコメント）を開始しました。
  • 環境省は2026年7月21日、「小型家電リサイクル制度の施行状況の評価・検討に関する報告書（案）」に対する意見募集（パブリックコメント）を開始しました。
  • 宣伝会議は2026年7月31日、改正資源有効利用促進法およびGX推進法に関する無料ウェビナーを9月9日に開催すると発表しました。

2. 技術・研究動向

  • 東京大学は「鉄スクラップの高度循環利用特別研究会」を立ち上げ、鉄スクラップ中の不純物による品質ばらつきの課題を克服し、高級鋼材へのリサイクルを促進するための産官学連携の議論を進めています。
  • 株式会社商研は、廃プラスチックなどの高精度選別ニーズの高まりに対応し、「ラバー選別機」「高電圧式静電選別機」「ジグザグ選別機」「電磁式金属選別機」の販売を強化しています。
  • KDDIは、総務省主催の「こども霞が関見学デー」にて、2026年7月29日と30日に「スマホ分解教室」を実施し、使用済みスマートフォンに含まれる金、銀、銅、レアメタルなどの貴重な資源の回収を通じて、リサイクルと資源循環の仕組みを学ぶ機会を提供します。
  • 2026年8月2日付の報告によると、中国における廃EVは2050年までに「都市鉱山」となり得るとされ、リチウム需要の89%を再供給できる可能性がある一方で、ニッケルは35%に留まるなど、素材ごとの循環可能性に大きな差があることが示唆されています。
  • 環境省の資源循環加速化モデル事業に採択された大林組は、建設解体現場から排出される廃窓（廃ガラス・廃アルミサッシ）の地産地消型リサイクルスキーム構築に向けた実現可能性調査に取り組み、クボタは独自の回転式表面溶融炉による焼却灰からの金属回収技術「ディープリサイクル」を活用した一般廃棄物の全量資源化システム構築事業を実施します。

4. 海外規制・市場

  • EUバッテリー規則は、EU市場で流通する電池のライフサイクル全体を管理し、2024年からGHG排出量算定、リサイクル材利用義務、回収率目標、バッテリーパスポート導入などの義務が段階的に適用されています。
  • 持続可能な製品のためのエコデザイン規則（ESPR）は2024年7月18日に施行され、EU市場のほぼすべての物理的製品にエコデザイン要件を拡大し、耐久性、修理可能性、リサイクル性など16の持続可能性側面を対象としています。
  • ESPRの一環として、2026年7月19日からは、繊維製品（衣類、履物、アクセサリー）の売れ残り品の廃棄が大規模企業に対して禁止されます。
  • EUは2026年の「循環経済法」採択を目指しており、域内の二次原材料単一市場の創設と、2030年までに循環率を現在の約12%から24%へ倍増させる目標を掲げています。
  • 米国では2026年7月31日、ドナルド・トランプ大統領が一部の産業廃棄物および電子廃棄物の輸出を制限する大統領令に署名し、レアアースや戦略的鉱物の国内確保と国内リサイクル強化を図る方針を示しました。
  • 中国は2017年から段階的に廃プラスチックや未選別古紙などの廃棄物輸入を禁止しており、この規制は現在も国際的な資源循環市場に影響を与え続けています。

4. 海外規制・市場

  • EUバッテリー規則は、EU市場で流通する電池のライフサイクル全体を管理し、2024年からGHG排出量算定、リサイクル材利用義務、回収率目標、バッテリーパスポート導入などの義務が段階的に適用されています。

  • ESPRの一環として、2026年7月19日からは、繊維製品（衣類、履物、アクセサリー）の売れ残り品の廃棄が大規模企業に対して禁止されます。
  • EUは2026年の「循環経済法」採択を目指しており、域内の二次原材料単一市場の創設と、2030年までに循環率を現在の約12%から24%へ倍増させる目標を掲げています。
  • 米国では2026年7月31日、ドナルド・トランプ大統領が一部の産業廃棄物および電子廃棄物の輸出を制限する大統領令に署名し、レアアースや戦略的鉱物の国内確保と国内リサイクル強化を図る方針を示しました。
